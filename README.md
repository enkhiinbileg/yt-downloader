# 🎥 Tatagch — YouTube Video & Audio Downloader

Орчин үеийн, хурдан бөгөөд хэрэглэхэд хялбар YouTube татагч програм. Видеог 4K хүртэлх бүх төрлийн чанараар, аудиог (MP3/M4A) нүүр зураг, цомогтойгоор, мөн хүссэн цаг минутаар нь хэсэгчлэн таслах боломжтой.

---

## ✨ Онцлог боломжууд

- **🎨 Орчин үеийн Desktop UI:** Microsoft Edge WebView2 дээр суурилсан, Glassmorphism загвартай, Dark/Light горимтой хэрэглэгчийн интерфэйс.
- **✂️ Хэсэгчлэн таслах (Trimmer):** YouTube тоглуулагч дээр харж байгаад эхлэх, дуусах хугацаагаа хулганаар чирж тохируулан зөвхөн хэрэгтэй хэсгээ секундын нарийвчлалтай татна.
- **⚡ Өндөр чанарын сонголт:** 4K, 2K, 1080p Full HD, 720p, 480p, 360p чанаруудаас бодит файлын хэмжээний тооцооллын хамт сонгох боломжтой.
- **🎵 Аудио таталт:** MP3 (320kbps, 192kbps, 128kbps) болон M4A. Дууны нүүр зураг (Cover art) болон мета өгөгдлийг автоматаар файлд шингээнэ.
- **📑 Playlist татах:** Бүтэн тоглуулах жагсаалтаас сонгосон эсвэл бүх видеог нэг дор татах.
- **📋 Clipboard интеграц:** YouTube линк хуулсан байхад `Ctrl + V` дарахад автоматаар таньж мэдээллийг татна.
- **📥 Татан авалтын менежер:** Татаж буй явц (%), хурд (MB/s), үлдсэн хугацааг (ETA) бодит хугацаанд харах, шууд файл нээх болон хавтсанд харуулах.
- **🛠 FFmpeg бэлэн:** FFmpeg тусад нь суулгах шаардлагагүй, програм анх удаа ажиллахдаа автоматаар тохируулна.

## 🚀 Ажиллуулах заавар

### 1. Эхлүүлэх (Шууд)
Windows дээр **`run.bat`** файл дээр 2 дарж ажиллуулна.
*(Хэрэв анх удаа ажиллуулж байгаа бол виртуал орчин `.venv` үүсгэж, шаардлагатай сангуудыг автоматаар суулгана).*

### 2. Гараар ажиллуулах (Хөгжүүлэгчдэд)
```bash
# Виртуал орчин үүсгэж идэвхжүүлэх
python -m venv .venv
.venv\Scripts\activate

# Сангуудыг суулгах
pip install -r requirements.txt

# Програмыг эхлүүлэх
python main.py
```

Хэрэв браузер дээр нээхийг хүсвэл:
```bash
python main.py --browser
```
